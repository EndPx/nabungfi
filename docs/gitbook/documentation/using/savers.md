# For Savers

## Add savings deliberately

Open the intended goal and choose Add savings. Select a network belonging to that goal, enter the USDC amount and review the transaction. On EVM, complete an exact approval first when required, then the deposit. Verify the original receipt and updated goal balance before treating the funds as saved.

## Understand the build

The Dashboard thumbnail follows funded progress. The detail model can be rotated, tilted, assembled or replayed. Its assembled count describes artwork; financial progress comes from verified vault assets. Sound and replay preferences do not alter money or eligibility.

## Finish the commitment

When the target is funded and authenticated reports are ready, choose Prepare completion and confirm the wallet request. Leave the goal in Verifying completion while the selected chains acknowledge readiness and completion. A zero-balance selected chain can still be waiting.

Cancel completion is a separate deliberate choice in Completion options. It returns the protocol toward saving; it does not accelerate a claim. After cancellation, wait for the chain acknowledgments and current reports before preparing again.

## Collect and retain the goal

When Claim becomes available, confirm each chain’s available savings. A chain with zero claimable USDC requires no empty withdrawal. Confirmed claims update Current savings and Claimed separately. The completed model and historical collected amount remain in Dashboard.

If the response is interrupted, use the recovery panel and original transaction reference. Do not substitute another goal’s hash or start a new request merely because the wallet dialog closed. The [recovery guide](../how-it-works/recovery.md) explains the different unsigned and attempted states.
