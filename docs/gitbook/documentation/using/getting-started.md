# Getting Started

Open [NabungFi](https://nabungfi.endpx.cloud) and choose Open app. Sign in with Google, email or a wallet. For Google/email accounts, the application prepares missing Ethereum and Solana embedded wallets and verifies their linked identities before opening the workspace.

{% stepper %}
{% step %}
### Verify your wallet addresses

Open Wallets. The EVM address serves Base, Arbitrum and Ethereum Sepolia; the Solana address serves Solana Devnet. USDC and native gas balances appear separately for each network, with the last verification time.
{% endstep %}
{% step %}
### Obtain testnet USDC

Open Faucets, copy the appropriate wallet address and use the USDC provider. Select the exact network at the provider. Confirm that the funds arrive in Wallets before trying a deposit. Provider eligibility and rate limits are outside NabungFi’s control.
{% endstep %}
{% step %}
### Create your first goal

Choose New goal in Dashboard, enter a name and positive USDC target, select a template and choose Solana plus the EVM networks you intend to use. Review the savings commitment before continuing.
{% endstep %}
{% step %}
### Complete guided setup

Review and confirm each selected vault creation and Solana initialization. Wait for linked-state verification. Continue setup resumes verified work if the flow was paused; an unknown wallet outcome must be reconciled first.
{% endstep %}
{% endstepper %}

Eligible embedded owners can request testnet gas sponsorship. External direct wallets need network-specific native gas. Wallet confirmation remains required in both cases. Sponsorship is not a supply of USDC.

On supported browsers, use Install app when available or the browser’s install/add-to-home-screen action. The PWA shell can open offline, but authentication, fresh financial reads and wallet operations require connectivity.
