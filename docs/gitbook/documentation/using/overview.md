# Overview

The app is organized around Dashboard, Activity, Wallets, Faucets and Settings. Dashboard creates and opens goals; Activity lists recorded wallet steps; Wallets displays linked addresses and token balances; Faucets opens funding providers; Settings controls app preferences and installation guidance.

| Guide | Use it when |
| --- | --- |
| [Getting Started](getting-started.md) | You need an account, wallets and testnet USDC |
| [For Savers](savers.md) | You want to create, fund and complete a goal |
| [Wallets and Faucets](wallets-and-faucets.md) | You need to distinguish wallet cash, gas and vault assets |
| [Frequently Asked Questions](faq.md) | A model, claim, setup or update state needs explanation |

The public landing animation introduces the building metaphor. It does not create a savings goal or represent an account balance. Open app starts the Privy sign-in flow before the authenticated workspace.

The current release uses testnet USDC and selected testnets. The guides describe actual app actions and preserve wallet confirmation. A faucet visit, model replay or dashboard filter does not send a deposit or claim.
