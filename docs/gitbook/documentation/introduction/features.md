# Features

## Multiple independent goals

Create several goals for the same account, with distinct targets, vault bindings and histories. Search and phase filters help organize the Dashboard. Collected goals retain their historical funded amount and complete model, while Current savings shows the assets still held in vaults.

## Multichain USDC savings

Select Solana plus one or more supported EVM networks. Deposit on any selected, fully linked network. Native gas and USDC remain network-specific even when EVM networks share one wallet address.

## Guided setup and wallet onboarding

Google, email and wallet sign-in use Privy. Missing wallet families are prepared before the workspace opens. Goal setup then guides the owner through selected EVM vault creation, Solana initialization and verified registration. Pausing preserves confirmed steps rather than replacing the goal.

## Nine construction templates

Choose a car, laptop, house, game console, camera, motorcycle, bicycle, smartphone or travel suitcase. Each has 100 stable primary parts. Rotate and tilt the model, assemble funded pieces, or replay a completed build. Legacy custom sculptures remain renderable; new prompt-generated models are deferred.

## Clear completion and collection

Prepare completion becomes the primary action when a funded goal is eligible. Verification and cancellation have distinct status messages. An available Claim is yellow; Waiting for chains explains why a claim cannot yet proceed. Cancelling a completion round does not withdraw savings.

## Wallet balances, faucets and explorers

Wallets reads USDC and SOL/ETH independently for every supported network, with refresh, last-verified times and unavailable states. Faucets links to token providers without implying a successful claim. Vault, wallet and transaction references link to the correct testnet explorer.

## PWA and original-request recovery

The app has an installable PWA shell for supported browsers. Updates wait while a wallet operation is unresolved. The offline shell does not queue financial actions or cache private API responses. Recovery preserves the original request identity, plan fingerprint and transaction hash.

## Eligible testnet gas sponsorship

Verified embedded owners can request sponsorship on the configured testnets. The wallet still asks for confirmation. The sponsored Base + Solana lifecycle has separate live receipt evidence; configuration on other testnets is not presented as an additional completed sponsored lifecycle.
